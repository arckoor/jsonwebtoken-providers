# jsonwebtoken-botan

A `CryptoProvider` for [jsonwebtoken](https://github.com/Keats/jsonwebtoken), backed by [Botan](https://github.com/randombit/botan) (via the [botan-rs](https://github.com/randombit/botan-rs) crate).

Use `jsonwebtoken_botan::install_default()` to install the provider.

Use the following table to select the correct version:
| `jsonwebtoken` version | provider version |
|:----:|:---:|
| 10.x | 1.x |
| 11.x | 2.x |
